Política de privacidad

CanalesIA es una herramienta de uso interno que solo accede a los canales de YouTube de su propietario para subir videos, agregarlos a listas de reproducción, subir subtítulos y publicar comentarios propios. No recopila, vende ni comparte datos de otras personas. Los permisos de Google se guardan solo en la computadora del propietario y pueden revocarse en cualquier momento desde https://myaccount.google.com/permissions.

El uso de datos de las API de Google cumple con la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Privacy Policy

CanalesIA is an internal tool that only accesses its owner's YouTube channels to upload videos, add them to playlists, upload captions and post the owner's own comments. It does not collect, sell or share anyone else's data. Google authorization tokens are stored only on the owner's computer and can be revoked at any time at https://myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services; see the YouTube Terms of Service (https://www.youtube.com/t/terms) and Google Privacy Policy (https://policies.google.com/privacy).
